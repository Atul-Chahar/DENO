# Swiss kinetic type
- A strict grid (12 columns); every element snaps to it. Left-aligned, flush, big.
- Two weights of one grotesk; numbers in tabular figures.
- Words enter on beats as solid blocks (masks or slides), never fades. Hard cuts between colour fields.
- Flat brand colours, one accent field per section.
- Avoid: drop shadows, gradients, centred everything, more than 8 words on screen.
