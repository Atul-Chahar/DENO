# Flat vector explainer
- Flat shapes from the brand palette, 2 px or no outlines, one texture at most.
- Structure: problem → what it is → 3 steps → proof → name and URL.
- Objects build from simple parts (draw on, then fill); transitions morph one object into the next.
- Characters are simple (head, body, arms) and act: anticipation, follow-through, no twinning.
- Avoid: clip-art people, isometric cities with nothing happening, text that narrates the picture.
