# Ink and watercolour
- Lines draw on with variable width; washes bloom outward and settle (pure functions of t with seeded noise).
- Paper ground; pigment never mixes muddy (use additive light for highlights).
- Slow pace: 3–5 s per read. Serif type for quotes.
- Line "boil" re-seeds 10–12 times a second, per element.
- Avoid: digital-looking gradients, glow, too many colours.
