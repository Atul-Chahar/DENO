# Living UI
- Real screens only: captured with `studio capture` or rebuilt faithfully in HTML (so they can zoom and act).
- The cursor moves on arcs, pauses ~8 frames before each click, and the click gets a small press and a tick.
- Zoom 1.4–1.8× into the area being used; pull back between actions to re-orient.
- One action every 3–4 s; the result of each action is the read.
- Type in UI appears at human speed with a caret.
- Avoid: fake data, invented features, 3D-tilted screens spinning for no reason.
