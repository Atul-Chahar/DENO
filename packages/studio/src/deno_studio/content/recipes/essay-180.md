# 3 min essay film
Treatment first with chapters. One recurring protagonist or object. ≤ 8 words on screen, held ≥ 2.5 s. Uncertain
facts go to `NOTES.md`, not the film. Use the multi-agent playbook: one scene-builder per chapter.
