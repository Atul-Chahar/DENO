# 30 s one-shape UI loop
List the states first (8–12): each is a UI moment (checkout, a toggle, a chart). One container shape morphs
between them, content enters after the container moves. Seamless: frame 0 equals the last frame, position and
velocity. `studio verify` runs the seam check. Great as a silent landing-page hero.
