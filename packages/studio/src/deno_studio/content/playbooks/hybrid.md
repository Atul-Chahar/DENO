# Generated media

Code-rendered motion design needs no generated pixels. Use image or video models only when the film needs photoreal
people or places, and only on the founder's own key.

- **Cost gate:** list every generation with its price and wait for the founder's OK. Show a still before each
  expensive step.
- **Identity lock:** an exhaustive character sheet; the first frame of each clip must match a start frame.
- **Camera lock:** who holds the camera, where it is, how it moves; no cuts inside a generated take.
- Generate on pure green (#00B140) and key it out, so code-rendered layers sit around it.
- Generated media is `license: generated` in `CREDITS.json`; check the provider's terms for commercial use.
